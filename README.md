# SnapReview
Official releases for **SnapReview**, a compact screenshot capture, review, and annotation application.

This repository contains compiled application releases and release notes only. The SnapReview source code is maintained separately in a private repository.

## Download

Download the latest version from the [Releases](../../releases/latest) page.

Each release includes:

- `SnapReview.exe`
- Version-specific release notes
- Bug fixes and feature information

## Installation

SnapReview is distributed as a portable Windows executable.

1. Download `SnapReview.exe` from the latest release.
2. Place it in a writable folder.
3. Run `SnapReview.exe`.

No installer is required.

## Automatic Updates

SnapReview checks this repository for new stable releases.

When a newer version is available, the application lets you:

- Download and install the update
- Postpone the update
- Ignore that specific version

Updates can also be checked manually from **Info/Settings → Check for Updates**.

## System Requirements

- Windows 10 or Windows 11
- 64-bit Windows recommended
